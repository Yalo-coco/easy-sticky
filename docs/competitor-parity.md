## 实施与验证计划

1. 数据模型增加可选富文本附件、归档及提醒字段，旧 JSON 无损读取；扩展回归检查。
2. 原生便签增加顶栏操作与富文本工具栏，保持非激活面板和跨 Space 行为。
3. 增加归档管理、系统通知和偏好设置数据入口。
4. 独立数据目录执行构建、模型/编辑器测试及 UI 保存重启验证，再交付可启动应用。

## 当前交互与数据语义

- 便签采用低饱和纸张色、轻量图标顶栏；底部格式工具默认收起，点击「Aa」展开。「…」提供收起、桌面模式、便签库、偏好设置和删除入口。
- 提醒在当前便签内部编辑，不创建额外窗口；支持快捷时间、自定义日期、保存及移除，结束后返回正文。系统首次通知授权仍由 macOS 管理。
- “收起”保留活动便签与提醒；“完成”归档并撤销提醒；“删除”二次确认后永久移除。
- 便签库区分当前与已归档，支持正文搜索；归档恢复不会重新激活旧提醒。
- 内容与图片以 RTFD 数据嵌入本地 JSON，`content` 保留纯文本用于搜索及通知摘要。新增字段均可选，兼容旧纯文本数据。
- 默认快捷键：新建 `⌥⌘N`、显示 `⌥2`、隐藏 `⌥3`、选区速记 `⌥⌘Y`，均支持单独修改与恢复默认；保留 `⌥⌘S` 切换显示。
- 首次提醒申请权限时，不提前保存提醒；允许通知后再次点击设置。等待授权不会锁死保存按钮。

## 0.3.2 交互改进

| 确定结论 | 代码或验证证据 | 边界 |
| --- | --- | --- |
| 当前便签直接处理 ⌘W / ⌘N，不依赖前台应用主菜单 | StickyPanel.performKeyEquivalent；UI 操作后独立 JSON 隐藏状态 | 关闭仅收起，不删除或归档 |
| 选区新建不再优先读取纯文本 | SelectedTextCapture.capture、CapturedSelection.read | 来源只提供纯文本时无法重建样式 |
| 普通粘贴、选区导入共用富文本解析和 RTFD 存储 | RichNoteEditor.pasteRichContent；HTML / RTFD 自动检查及 UI 粘贴 | 原来已丢失的格式需重新选取原文 |
| 提醒保持内嵌，日期、小时、分钟独立选择 | ReminderWheelPicker；日期边界和夏令时检查 | 手势自动化不可用，触控板与拖动手感待人工确认 |

滚轮视觉参考 [Apple Pickers 指南](https://developer.apple.com/design/human-interface-guidelines/pickers)，以原生 AppKit 实现中心选中带、相邻值渐淡、键盘及辅助功能增减操作。日期摘要显示具体年月日和时间；过去时间不可保存，取消不会改动已有提醒。

验证：核心检查 16 项、原生功能检查 52 项通过；UI 已验证新建、关闭单张、日期增减、分钟方向键、快捷时间、提醒保存和移除、富文本粘贴及重启保留。独立测试包缺少辅助功能授权，跨应用选区捕获端到端验收待确认；未代用户修改系统权限。

0.3.2 已在原启动路径运行；升级前后的 6 张便签 ID、正文、富文本、颜色、提醒及归档字段一致。旧应用移入废纸篓，源码和用户数据保留。

## 0.3.3 原图存储与自适应展示

| 确定结论 | 证据 | 边界 |

| 文件插入保存原始字节，不重绘生成缩小图片 | RichNoteEditor.insertImageData / imageDocument；PNG、JPEG、TIFF 逐字节比较 | 来源本身已压缩的图片无法还原 |
| 窗口宽度变化仅更新附件显示尺寸 | updateImageLayout / OriginalImageCell；真实 NSWindow 宽窄往返测试 | 不放大小图；长图保持比例纵向滚动 |
| 保存重读、多张同名图片不会改变或覆盖原始数据 | RTFD 往返、同名附件测试 | 旧版已缩小附件需重新插入 |
| 图片和相邻正文在实际窗口内正常绘制 | 独立数据目录原图附件 UI 检查 | 文件选择器自动化有焦点问题，完整文件选择操作待人工确认 |

验证通过：原生功能检查 85 项、核心检查 16 项，release 构建和签名校验通过。尺寸变化覆盖正文内边距、反复缩放、仅改变高度、同名多图、小图、长图以及重新加载到不同宽度。窗口布局变化不生成内容编辑或撤销记录。
