# Easy Sticky（轻便签）产品方案

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | Easy Sticky（轻便签） |
| 产品形态 | macOS 原生桌面应用 |
| 文档状态 | MVP 实现基线 |
| 版本 | v0.2 |
| 更新日期 | 2026-08-27 |

## 2. 一句话定义

Easy Sticky 是一款打开即写、跨 macOS 桌面空间持续悬浮的本地便签工具，让用户把临时信息放在眼前，并能用系统标准快捷键快速复制和粘贴。

## 3. 背景与用户问题

用户在工作或学习中经常需要暂存一段不会长期保存、但又不能立刻忘记的信息，例如临时链接、错误信息、会议号码、待办句子或代码片段。现有方案通常有以下摩擦：

- 打开文档、聊天或任务工具的路径太长，记录一条信息的成本高。
- 普通窗口会被其他应用遮挡，切换 macOS 桌面空间后还要重新寻找。
- 复杂笔记工具带来账号、同步、格式和组织成本，不适合只记一两句话。
- 只读展示或系统剪贴板无法承载多条可回看的临时内容。

### 3.1 产品目标

1. 从想到记录到开始输入不超过一次明确操作。
2. 便签在用户切换桌面空间时仍保持可见，并尽量留在用户设定的位置。
3. 复制、粘贴符合 macOS 习惯，不要求学习新的编辑方式。
4. 默认本地保存、无账号依赖，降低隐私和使用门槛。

### 3.2 非目标（MVP 不做）

- 云端同步、多人协作和账号体系。
- 富文本排版、Markdown 渲染、图片/附件和手写。
- 提醒、日历、任务管理、全文搜索和复杂标签体系。
- 移动端或 Windows 版本。
- 将便签内容上传到服务器进行分析。

## 4. 目标用户与核心场景

### 4.1 目标用户

- 需要频繁在多个应用之间搬运信息的开发者、设计师和产品同学。
- 上课、会议或远程协作时需要暂存短文本的学生和办公用户。
- 不想维护完整知识库、只需要一个“放在桌面边上”的临时记事本的人。

### 4.2 核心场景

| 场景 | 用户行为 | 期望结果 |
| --- | --- | --- |
| 临时记录 | 打开应用并输入一句话 | 便签立即出现，内容自动保存 |
| 对照信息 | 切换到另一个 macOS 桌面空间 | 便签仍在同一相对位置，可继续查看 |
| 搬运文本 | 从网页/终端复制到便签，或从便签复制出去 | 使用 `⌘C` / `⌘V` 即可完成 |
| 多条暂存 | 新建第二张便签 | 每张便签独立编辑、移动和关闭 |
| 颜色区分 | 为不同用途的便签指定颜色 | 每张便签独立选色，重启后保持选择 |
| 选区速记 | 在任意应用选中文本并按自定义快捷键 | 选区立即成为一张可编辑的悬浮便签 |
| 暂时收起 | 不想看到便签但不想丢内容 | 隐藏窗口，稍后可从菜单栏或快捷键恢复 |

## 5. 产品原则

1. **先写再整理**：打开后默认进入可编辑状态，不用先选择空间、模板或分类。
2. **稳定地在场**：悬浮和跨桌面是核心能力，窗口行为要可预测且可关闭。
3. **少即是多**：MVP 只保留记录、查看、复制、粘贴和窗口管理所需的控件。
4. **本地优先**：没有网络也能正常使用，内容默认只存储在本机。
5. **尊重 macOS 习惯**：遵循原生窗口、菜单、快捷键、权限和辅助功能体验。

## 6. MVP 功能范围

### 6.1 启动与入口（Must）

- 双击应用、从 Launchpad 或 Dock 点击后直接进入主便签窗口。
- 首次启动不要求登录，不弹出非必要的引导或权限请求。
- 应用运行后在菜单栏提供入口，支持显示/隐藏全部便签、新建便签和退出应用。
- 关闭主窗口不等于退出应用；用户可从菜单栏重新打开。
- 退出应用后再次打开，应恢复上次未删除的便签。

### 6.2 便签编辑（Must）

- 支持新建、编辑、删除（或移入回收站）便签。
- 每张便签至少包含正文和创建/更新时间；正文为空时也允许暂存。
- 输入后自动保存，不需要显式点击“保存”。
- 支持 macOS 标准文本编辑能力：撤销/重做、全选、复制、剪切、粘贴。
- 粘贴纯文本时保持可读性，不因来源应用带入不可见格式或脚本。
- 应用异常退出后，重新打开时恢复最近一次自动保存内容。

### 6.3 悬浮与跨桌面（Must）

- 便签默认显示在其他普通应用窗口之上，但不能遮挡系统级安全弹窗或权限弹窗。
- 用户切换 macOS Spaces/桌面空间后，便签继续显示。
- 每张便签保留用户最近一次设置的屏幕、位置和尺寸；显示器变化或分辨率变化时自动调整到可见区域。
- 支持“固定在所有桌面”和“仅当前桌面”两种模式；MVP 默认使用“所有桌面”。
- 支持置顶开关。关闭置顶后，便签仍属于当前桌面窗口，不再覆盖其他应用。
- 用户可以拖动标题栏移动便签、拖动边缘调整尺寸；重启和切换桌面后保持结果。
- 便签不能因切换全屏应用而永久丢失；退出全屏后应恢复可见。

### 6.4 便签管理（Should）

- 支持创建多张便签，每张便签拥有独立窗口。
- 每张便签可独立选择颜色，MVP 提供暖黄、杏橙、玫瑰粉、薰衣草紫、天空蓝、薄荷绿、鼠尾草绿和雾灰 8 种低饱和颜色；不引入自定义取色器或复杂主题编辑器。
- 颜色通过标题栏可视化色板或菜单栏选择，当前颜色有明确选中态；选择后即时生效并随便签自动保存。
- 每张便签独立提供“置顶”和“跨所有桌面”两个快捷按钮，按钮用实心/描边状态区分开关，状态自动保存。
- 支持“隐藏全部”与“显示全部”，隐藏不删除内容。
- 删除前提供一次可撤销的操作；MVP 可采用短时撤销提示，不要求完整回收站页面。

### 6.5 快捷操作（Should）

- 提供一个不与常用系统快捷键冲突的全局新建便签快捷键（候选：`⌥⌘N`）。
- 提供显示/隐藏全部便签的全局快捷键（候选：`⌥⌘S`）。
- 提供“从选中文本新建便签”的可配置全局快捷键，默认 `⌥⌘Y`；用户可在快捷键设置中直接录入组合键。
- 触发选区速记时优先通过 macOS Accessibility API 读取当前选区；不支持直接读取的应用可降级为模拟 `⌘C`，完成后恢复原剪贴板。
- 辅助功能权限只在首次使用选区速记或用户主动授权时申请，不阻塞普通便签能力。
- 快捷键冲突时允许用户在设置中修改或关闭，不影响鼠标和菜单栏使用。
- 文本编辑区继续使用系统默认的 `⌘C`、`⌘V`、`⌘X`、`⌘A`、`⌘Z` 等快捷键。

> 快捷键是建议项，最终组合需要在实现前做一次系统和常见应用冲突检查。

## 7. 关键用户流程

### 7.1 首次使用

1. 用户启动 Easy Sticky。
2. 屏幕上出现一张空白便签，光标自动聚焦正文。
3. 用户输入内容，应用在短暂空闲或内容变更后自动保存。
4. 菜单栏出现 Easy Sticky 图标，用户无需额外配置即可继续使用。

### 7.2 切换桌面空间

1. 用户在桌面空间 A 创建或移动便签。
2. 用户通过触控板、快捷键或 Mission Control 切换到桌面空间 B。
3. 便签在 B 中按原屏幕和相对位置出现。
4. 用户可直接查看、编辑、复制；返回 A 后状态保持一致。

### 7.3 复制与粘贴

1. 用户在其他应用中复制文本。
2. 用户点击便签正文，按 `⌘V` 粘贴。
3. 用户选中便签中的部分或全部文本，按 `⌘C` 复制。
4. 用户切换到目标应用，按 `⌘V` 使用复制内容。

### 7.4 隐藏与恢复

1. 用户点击菜单栏图标，选择“隐藏全部便签”，或使用全局隐藏快捷键。
2. 便签窗口从屏幕消失，但内容和位置状态保留。
3. 用户再次点击菜单栏图标并选择“显示全部”，便签恢复。

## 8. 信息架构与界面草图

### 8.1 窗口结构

```text
┌────────────────────────────┐
│                  ⌖  ▣  ◉  │  ← 聚焦/悬停时显示：置顶、桌面、颜色
├────────────────────────────┤
│                            │
│  点击后直接输入……          │  ← 正文编辑区
│                            │
│                            │
└────────────────────────────┘
```

- 默认窗口使用圆角、轻阴影和适度透明度，保证与桌面背景有足够对比度。
- 控件只在鼠标悬停或窗口获得焦点时展示，减少视觉噪音。
- 内容区保持完整纸张底色，操作控件使用独立的轻量材质层，避免装饰干扰正文。
- 色板采用 4×2 圆形色块，兼顾快速扫描、选中反馈、ToolTip 和 VoiceOver 标签。
- 关闭按钮只关闭当前便签；删除操作放入“更多”菜单，降低误触风险。

### 8.2 菜单栏菜单

```text
Easy Sticky
├─ 新建便签
├─ 显示全部便签
├─ 隐藏全部便签
├─ 固定到所有桌面        ✓
├─ 置顶显示              ✓
├─ 设置...
└─ 退出 Easy Sticky
```

### 8.3 视觉参考与取舍

- [Apple Stickies](https://support.apple.com/en-asia/guide/stickies/welcome/mac)：参考其“每张便签独立颜色、自由移动缩放、可置顶”的直接操作模型，保留纸张感和低学习成本。
- [Google Keep](https://workspace.google.com/products/keep/)：参考其低饱和颜色编码、置顶和快速扫描思路，但不引入卡片列表、标签体系或信息密度较高的工具栏。
- [Microsoft Sticky Notes](https://support.microsoft.com/en-us/windows/apps/stickynotes/get-started-with-sticky-notes)：参考其把单张便签颜色放在轻量入口中的做法，改造成更符合 macOS 的悬停操作栏和原生 Popover。
- [Apple Human Interface Guidelines: Color](https://developer.apple.com/design/human-interface-guidelines/color) 与 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：颜色保持一致含义并提供明暗外观；材质只用于操作控件层，不覆盖正文内容层。

Easy Sticky 的 8 色色板、4×2 圆形选择器、明暗两套色值和“三按钮悬停操作栏”均为本项目的组合设计，不直接复刻任一现有产品界面。

## 9. 功能需求与验收标准

| 编号 | 功能 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-01 | 一键启动 | Must | 从 Finder、Dock 或 Launchpad 启动后，用户无需登录或配置即可看到可编辑便签 |
| FR-02 | 自动保存 | Must | 输入内容后关闭并重新打开应用，内容仍完整存在；异常退出后恢复最近一次自动保存 |
| FR-03 | 新建/关闭便签 | Must | 可新建多张便签；关闭单张便签不影响其他便签；退出后再次打开仍能找到未删除便签 |
| FR-04 | 跨桌面显示 | Must | 在至少 3 个 Spaces 间往返切换 10 次，便签持续可见且不重复创建窗口 |
| FR-05 | 固定位置 | Must | 移动或调整尺寸后切换桌面、重启应用，便签回到上次保存的位置或可见区域内的等比例位置 |
| FR-06 | 置顶控制 | Must | 开启时位于普通应用之上，关闭后不再强制覆盖普通应用；两种状态可反复切换 |
| FR-07 | 复制/粘贴 | Must | `⌘C` / `⌘V` / `⌘X` / `⌘A` 在便签内和应用间按 macOS 预期工作，至少覆盖中英文、数字、换行和长文本 |
| FR-08 | 隐藏/显示全部 | Should | 菜单栏和快捷键均可隐藏、恢复全部便签，隐藏过程中不丢内容 |
| FR-09 | 本地优先 | Must | 断网时核心功能可用；便签内容不上传服务器，应用不依赖账号 |
| FR-10 | 多显示器 | Should | 拔插外接显示器或改变主屏后，便签自动移动到当前可见屏幕，不出现在屏幕外 |
| FR-11 | 独立颜色 | Should | 任意两张便签可设置不同颜色；重启后各自保持；标题栏色板与菜单栏均显示当前选中态 |
| FR-12 | 独立窗口按钮 | Must | 每张便签的置顶、跨桌面按钮均独立生效，图标显示当前状态，重启后状态保持 |
| FR-13 | 选区速记 | Should | 在其他应用选中文本后按自定义快捷键，1 秒内生成包含原文的便签；无选区时给出明确提示；原剪贴板内容不被长期覆盖 |

## 10. 数据与隐私

### 10.1 本地数据建议

每张便签至少保存以下信息：

- `id`：本地稳定标识。
- `content`：正文内容。
- `createdAt`、`updatedAt`：创建和最后修改时间。
- `frame`：窗口所在屏幕标识、位置和尺寸。
- `displayMode`：所有桌面/当前桌面。
- `isAlwaysOnTop`、`isHidden`：窗口状态。
- `theme`：颜色或主题标识（如 MVP 纳入）。

### 10.2 隐私约束

- 默认只写入 macOS 用户本地应用数据目录。
- MVP 不接入分析 SDK、不上传正文、不读取系统剪贴板历史；只在用户主动执行复制/粘贴时读写当前剪贴板。
- 需要系统权限时遵循最小授权原则，并在设置中说明用途；核心记录功能不应依赖通讯录、麦克风或屏幕录制权限。
- 导出、同步等未来能力若引入网络，必须单独设计开关、隐私说明和数据删除机制。

## 11. 非功能要求

- **启动体验**：正常机器上从点击应用到出现可输入便签应接近即时，目标为 1.5 秒内。
- **稳定性**：切换 Spaces、全屏应用、显示器连接状态和系统休眠唤醒后不崩溃、不丢内容。
- **性能**：常驻一张便签时保持低 CPU 占用；创建 20 张便签仍可正常拖动和输入。
- **可访问性**：支持 VoiceOver 可识别的窗口标题、编辑区和菜单项；支持键盘完成新建、隐藏、显示和退出。
- **兼容性**：首个版本明确最低 macOS 版本，并在该版本和当前最新版上验证窗口层级、Spaces 和剪贴板行为。
- **更新安全**：应用升级不覆盖用户便签数据；数据格式变更需提供向后兼容或迁移。

## 12. 埋点与成功指标（本地可选）

MVP 默认不上传用户内容。如确需衡量产品质量，只记录不含正文的本地统计，并在后续获得用户同意后再设计匿名上报。

建议关注：

- 启动成功率和启动耗时。
- 首次启动后 1 分钟内创建便签的比例。
- 自动保存成功率、异常退出后的恢复成功率。
- 跨 Spaces 场景下的窗口存活率。
- 复制/粘贴操作成功率和崩溃率。
- 一周内重复启动和重复创建便签的用户比例。

## 13. 版本规划

### V0.1：可用的本地便签（MVP）

- 一键启动、单/多便签、自动保存。
- 固定位置、置顶、跨 Spaces 显示。
- 系统标准复制/粘贴。
- 菜单栏显示/隐藏和退出。
- 基础异常恢复与多显示器可见性处理。
- 每张便签独立 8 色主题和简洁的悬停操作栏。
- 可配置的选区速记快捷键及按需辅助功能授权。

### V0.2：更顺手

- 可配置全局快捷键。
- 透明度和字体大小。
- 最近关闭便签的撤销恢复。
- 启动时自动恢复或登录项设置。
- 更细粒度的“所有桌面/当前桌面”与显示器选择。

### V1.0：可扩展但不打扰

- 可选的本地导出/导入。
- 可选同步（先明确端到端加密和隐私策略）。
- 搜索、归档和轻量标签。
- 面向开发者的代码片段展示优化，但不改变默认的简洁体验。

## 14. 风险与应对

| 风险 | 影响 | 应对方案 |
| --- | --- | --- |
| macOS Spaces 对窗口集合行为的限制或系统版本差异 | 便签在切换桌面时消失、重复或位置漂移 | 在目标 macOS 版本矩阵中验证 `all spaces`、全屏和休眠唤醒；将模式做成可切换配置 |
| 置顶窗口遮挡用户操作 | 用户觉得“碍事”并关闭应用 | 提供一键隐藏、置顶开关、透明度/位置调整；不要覆盖系统级弹窗 |
| 自动保存时机不当 | 崩溃或强退时丢失最近输入 | 内容变更后节流保存，并在应用退出/失焦时再保存一次；启动时做数据校验 |
| 外接显示器变化导致窗口离屏 | 用户误以为便签丢失 | 启动、屏幕配置变化和显示器拔出时校正窗口到可见区域 |
| 全局快捷键冲突 | 快捷键无法使用或影响其他应用 | 默认组合先做冲突检查，注册失败时提示并允许关闭/修改 |
| 便签数量增长造成干扰 | 界面变乱、性能下降 | MVP 控制单窗口轻量渲染；后续增加隐藏、归档和批量管理 |

## 16. 待确认决策

以下事项不影响 MVP 先做本地记录，但在进入实现前需要产品与开发确认：

1. 最低支持的 macOS 版本。
2. “所有桌面”是否默认开启，还是首次启动时让用户选择。
3. 便签关闭按钮的语义：仅隐藏、关闭窗口，还是直接删除。
4. 是否在后续版本纳入透明度和字体大小（颜色已确认纳入 MVP）。
5. 是否需要登录项（开机启动）以及默认是否关闭。
6. 全局快捷键的最终组合与冲突处理方式。
7. 是否允许用户手动导出本地便签文件，以及导出格式。
